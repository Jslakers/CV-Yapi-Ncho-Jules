Ce dépôt contient le code source de mon portfolio et CV en ligne cinématographique, développé avec **React 19**, **Vite** et **GSAP**.

---

## 🚀 Fonctionnalités

- **Expérience Visuelle Moderne** : Palette épurée blanc & bleu tech avec animations fluides propulsées par **GSAP** & **ScrollTrigger**.
- **Sections Clés** :
  - **Accueil & Présentation** : Profil, coordonnées et vision.
  - **Parcours & Expériences** : Licences UJA, certifications ICDL Africa, baccalauréat.
  - **Tableau de Bord des Compétences** : Programmation (C/C++, Python), Administration Linux/Windows, Réseaux Cisco, Cybersécurité & Supervision.
  - **Projets Techniques** : Fiches détaillées (Architecture sans fil TPDECO, Wazuh, Hotspot MikroTik).
  - **Contact & CV** : Téléchargement direct du CV en PDF et prise de contact.

---

## 🛠️ Stack Technique

- **Framework** : [React 19](https://react.dev/)
- **Bundler** : [Vite](https://vitejs.dev/)
- **Animations** : [GSAP 3](https://greensock.com/gsap/) (avec ScrollTrigger)
- **Icônes** : [Lucide React](https://lucide.dev/)
- **Polices** : Plus Jakarta Sans, Inter, Fira Code

## 💻 Démarrage en local

1. **Cloner le dépôt** :
   ```bash
   git clone https://github.com/Jslakers/CV-Yapi-Ncho-Jules.git
   cd CV-Yapi-Ncho-Jules
   ```

2. **Installer les dépendances** :
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```

4. **Compiler pour la production** :
   ```bash
   npm run build
   ```
